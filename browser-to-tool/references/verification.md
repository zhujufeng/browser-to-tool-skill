# 验证与交付清单

按实际需求选用，不强迫每个小工具搭完整测试框架。测试代码也放在任务文件夹的`代码/`中，业务结果放`输出/`；可重建临时环境及时清理。

## 最小闭环

1. 在没有真实账号的合成样例上验证核心分支、失败和输出，不先拿整个后台当试验场。
2. 记录实际命令、必要版本、退出结果、输出文件路径与检查结论。截图需真实查看，不能只报告“文件存在”。
3. 在授权范围内做一次小规模真实操作核对；没有授权/环境就明确记“未验证”，不使用替身结果冒充真实网站或真实模型表现。
4. 从使用者角度照使用说明运行，确认首次依赖准备与日常步骤分开。机器没装Node/Python/Git时不能给一条必然失败的命令了事；先走环境检测与必要准备。

## 非开发同事的日常使用验收

交付可重复使用的工具时，在隔离合成环境按真实入口检查下列三件事；一次性结果不强制制作启动器。已有等价检查直接复用，不额外搭测试平台。

1. **首次使用**：完成获准的一次性安装/依赖准备后，通过成品插件按钮或脚本启动文件，从新进程完成到取得文件的链路，不依赖编码助手会话、工具服务或模型调用。日期、字段、单位可核对；同事不需要编辑源码、终端命令或开发者控制台。测试可由助手驱动，但运行的是成品入口，不能临时注入代码代替成品功能。
2. **再次使用**：正常退出测试工具并释放开发期专用连接后，按同一入口再次启动并修改日期/范围，确认产生本轮新结果、保留旧结果，不重装或重新开发。核对未依赖开发时的临时端口、候选ID、助手私有浏览器连接或进程内认证；必要的浏览器及会话由成品按已验证流程准备。不关闭个人浏览器或用户的编码助手；已获准真实全量后，用合成数据检验再次运行，不重复整店采集。
3. **失败恢复**：模拟登录失效和部分结果，确认成品自行停止、输出不冒充完整、直接提示用户在哪里重新登录及如何再运行，不以找Codex作为普通登录恢复步骤。恢复后核对账户与筛选；未实现并验证断点续传时，不承诺从断点继续。另测权限不足不得通过换账户或重试绕过。接口变化等需修改代码的问题才转交维护。

逐项记录入口、操作、结果和未测范围。助手执行通过不等于同事独立使用通过；真实同事试用另记耗时、求助次数及业务核对结果。生成了说明但没跑过入口，只能写“入口已准备，未验证”。

### 启动和结果定位

沿用已有合适界面，没有界面时按本机系统选最小入口，不为一个采集脚本另造平台：

| 成品 | 最小入口与检查 |
|---|---|
| macOS脚本 | 任务根目录放`开始采集.command`，设置执行权限；按启动文件自身位置定位代码、使用已准备的运行时，路径加引号；失败后保留窗口中的中文提示。双击体验需实际检查，命令行执行过同一文件只能证明进程链，不能冒充Finder双击已验收 |
| Windows脚本 | 任务根目录放`开始采集.cmd`或已有应用快捷方式；以`%~dp0`等原生方式定位目录，使用已准备的运行时，保留失败提示；不要求用户执行PowerShell策略绕过 |
| Linux脚本 | 采用当前桌面实际支持的可打开入口，并验证执行权限；无图形桌面时说明限制，不能仅将`.sh`改名就宣称可双击 |
| 浏览器插件 | 明确浏览器、插件名称和按钮位置；从按钮走完整链路，导出后提供真实下载文件或下载记录的入口 |

本地脚本从**无关工作目录**启动一次，任务路径包含空格/中文；确认文件仍在任务的`输出/`内，运行时不是偶然从开发Shell继承。再运行一次，旧结果字节不变；时间戳命名也处理同秒冲突，不能只用写入模式`w`覆盖固定文件。按任务需要采用独占创建或安全的临时写入与发布，失败不留“完整成功”文件。插件则检查浏览器真实下载记录及文件定位、同名文件处理，不强求下载到桌面任务目录。

打开实际生成的CSV/JSON核对内容，而不是只看退出码和文件存在。完成提示显示完整/部分、数量；本地脚本给绝对文件路径和打开文件/所在目录的入口，插件给真实下载记录的入口。打开失败保留结果，不能为了打开文件重新采集。日常启动时不静默安装/升级依赖。缺依赖、断网和TLS错误应保留可读提示，按[环境准备](setup.md)处理。

### 完成措辞由证据决定

| 最强证据 | 可以报告 |
|---|---|
| 语法、导入或`--help`通过 | 代码已准备，采集尚未验证 |
| 合成数据从启动入口到导出通过 | 本地流程已验证，目标网站仍待验证 |
| 从实际入口取得并核对真实小样本 | 小样本可用；未测全量/跨页/额外字段逐项列明 |
| 获准范围内取数并核对字段、范围与终点 | 该范围已验证；同事能否独立使用需另记真人试用 |

没有可访问目标时仍可完成实现和合成检查，但交付标题应写“待验证版本”。证书修复后的语法通过不能写“证书问题已修复”。

## 采集或导出

- 路线：自行调查接口时，实际观察查询，验证相同筛选的一页HTTP请求与下一页/游标；已证明一次全量、本地分页或合法单页/零条时核对相应终点，不猜第二页参数。复用可信站点库/官方API时按HTTP参考核对实际字段和跨页结果，不强求重新监听其内部协议。不要用成功截图、下载按钮或一次200响应代替取数验证；采用官方导出/DOM回退需有记录的原因。
- 认证：只验证正常授权会话；分别说明独立HTTP、浏览器关联客户端和浏览器fetch，后两种不能声称无需浏览器。伪造Cookie/令牌/签名应在进入模型与成果前被阻止，重定向和next链接不能跨授权域传递认证。
- 方法：覆盖真实GET/POST查询或GraphQL query；未知写操作不试跑，业务错误/登录HTML/GraphQL errors不能误判成功。重试只限已确认安全的请求，429按服务要求退避，401/403停止。
- 范围：当前页/当前筛选/所有店铺/历史数据区别明确；字段名称和日期时区经观察或确认。
- 分页：第一页起点、连续页码或游标、重复页、空页、终点、总数变化、稳定唯一ID、重复/缺失及预算上限。
- 失败：登录过期、权限不足、请求超时、非JSON、接口结构变化、结果过大、用户停止。不能静默成功或拿旧结果冒充新结果。
- 数据：全量前核对少量业务CSV样例的列名、顺序、指标含义、金额/比例单位与空值；内部包装/类型/基准值不默认展开。合法补充指标缺值需证据，不能擅填零或因缺值漏掉整列。大整数ID精确保留、字符编码正确、日期不跨界；CSV面向Excel时防公式注入，JSON不能悄悄改变类型。
- 模式与字段：列表接口/扁平提取通常不等于详情提取。分别检查实际开关及其数据来源，用少量样本对照正式导出中必需列的值；必需字段未取得就是未完成，非必需字段不可用则明确省略/留空的含义。不因生成了列头或导出很多行就承诺全部字段齐全。
- 完整性：只拿到部分则显式标“部分/失败”；不能只因总条数相同就声称完整快照。独占或原子写入，旧输出不直接覆盖，失败不破坏已有成果。

## 插件、脚本、应用

- 插件在独立浏览器跑合成完整链路，验证弹窗→后台→MAIN/ISOLATED执行环境→请求→进度→持久化→导出。记录测试源码/manifest版本和本轮runId、新结果；不能等到旧“完成”就宣布通过。缓存疑点先核实加载版本，必要时仅在合成测试用临时路径/新扩展ID和空存储，不迁移个人profile，不让用户日常重装丢旧记录。真实安装验收另取授权，仍在选定业务会话进行。只运行hook脚本、只mock Chrome接口或只看截图都不等于扩展通过。
- 分别测试“尚在初始化”“请求已发出”时取消；无controller时也不能让排队任务迟到后启动。停止、导航、worker恢复均要隔离旧run/文档。
- 存储失败不能报完成或删除旧记录；时钟回拨后应仍导出最后成功写入的记录。进度更新不能覆盖用户尚未保存的设置。
- 声明权限只覆盖需要的网站和能力；开发版重载需按浏览器正常开发者模式流程，不修改企业策略或用安全绕过参数。
- 脚本写最小可运行检查，不把凭据写进源码或命令行历史。依赖按需使用虚拟环境/项目局部安装；不要为了方便全局安装一堆包。
- 应用检查主要流程、输入校验、错误提示和可访问性；不以“页面看起来正确”替代功能验证。
- 实际账号写入、安装插件、外发数据、提交/推送、部署发布均需要对应授权；只生成代码不自动执行业务副作用。

## 日期与定时

- 明确业务时区、起止边界、夏令时（如适用）、昨天/本月等相对日期的计算时刻。
- 重复运行不重复写入或覆盖历史，部分失败可识别；登录过期可见，不复制Cookie到交付物来假装永久登录；程序通过授权的本地会话机制使用认证不等于允许泄露凭据。
- 说明机器关机、休眠、断网及浏览器关闭时的实际行为；需要常在线环境才可靠就直说。
- 选择已有系统计划任务能力，不无故再造常驻平台。注册/启用/取消均有明确路径；启用需用户授权。
- 关闭定时后，迟到或已排队的闹钟也必须再次检查启用状态；不能仅清除下一次闹钟。
- 区分“已生成定时代码”“已注册任务”“已实跑验证”。不能把下一次计划时间当执行成功证据。

## 反复失败时

同一个错误再次出现而没有新证据，就停止追加猜测分支。说明故障属于会话/权限、界面定位、请求构造、接口业务状态、分页、消息链还是存储；在本地返回过滤后的阶段、错误类别和必要结构，不能把整份底层异常/头/HAR交给模型。每轮修改带一个对应的失败检查，再请用户试用。

分别报告静态检查、合成数据逻辑、真实浏览器扩展链、真实网站小样本、真实全量及宿主模型行为；一个通过不替另一个背书。截图必须在原会话生成并实际查看，不为了截图关闭用户刚登录的窗口。全量请求有明确预算，完成后从保存记录验证生产导出代码，不为截图或收尾再采一遍；遇到限流/风控不能换profile规避。借用浏览器只断开已核实的连接，不拿个人Chrome试验关闭语义；临时筛选逐项恢复核对，撤销授权后报告未恢复项，不绕过拒绝。

## 文件交付

- 所有重要调查依据、分析结论、代码、验证结果和使用说明都在同一个桌面任务文件夹；续作沿用旧目录。
- 重要记录随做随保存。中断时留下当前状态、已完成部分、确切阻塞和下一步，不留空的“全部完成”模板。
- 说明一条最短日常运行方式、输出在哪里、怎么改日期/范围、失败与停止方式，以及尚未验证的边界。
- 分享时排除profile、凭据、依赖缓存、未经允许的业务样例和截图；系统本来同步桌面时提醒其影响，不擅自改变同步设置。
- 最终回答给准确路径与真实状态，未获新授权不安装/启用后台、不提交/推送/发布。
