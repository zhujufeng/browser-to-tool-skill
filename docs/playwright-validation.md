## 可重复检查

在仓库根目录、依赖已按授权准备后执行：

```sh
python3 维护者/check.py
node --test 维护者/browser*.test.mjs
# macOS/Linux可见窗口验证：
BROWSER_TEST_HEADED=1 node --test 维护者/browser.test.mjs
```

可通过`PLAYWRIGHT_BROWSERS_PATH`指定测试浏览器缓存，`BROWSER_TEST_EVIDENCE_DIR`保存合成截图。不要将这两个路径指向个人浏览器资料。Windows浏览器集成测试当前跳过，运行器本身明确阻止启动；跳过不算通过。

## 已运行通过

Node的5个测试场景组均通过（一个场景组包含多条断言，不将它夸大为五个网站验证）：

1. **数据处理**：结构而非原文、白名单投影、敏感键、已知秘密镜像键/数字、URL参数名、巨大ID字符串和POST数字字面值保留。
2. **真实Chromium会话**：合成登录后正常关闭，重开复用Cookie；同profile占用拒绝；先监听POST再HTTP一页/下一页；控件检查、日期输入、查询按钮；旧文档/旧观察的迟到请求失效；停止中断请求。
3. **跨进程CLI/worker**：启动命令结束后仍能后续调用；Host/Origin/token边界、旧session、同profile占用；原子JSON输出、不覆盖、目录越界/符号链接；保留profile；停止、重启、空闲退出；工作目录移动/日志不可写仍完成空闲清理；仅清理已死worker元数据的恢复。
4. **认证/GraphQL**：响应Set-Cookie轮换后的短Cookie镜像值在输出文件中脱敏；同文档、无Cookie的Bearer A→B导致旧候选失效；首个query但选中后续mutation在发送前拒绝，正常命名query仍通过。
5. **启动取消**：初始导航挂起时终止启动CLI，释放合成响应后确认worker退出、元数据清理，同profile可以重新启动。

另单独运行可见窗口测试通过，读取了保存的合成截图。首次可见窗口测试揭示macOS中文“正在现有的浏览器会话中打开”未映射为profile占用，已修正并重测。截图只是合成页面视觉证据，不是四宿主交互或真实业务证明。

覆盖的HTTP失败包括401、429、HTML登录返回、超过解析上限、跨origin重定向不跟随。失败不自动打印原始异常/响应，也不假报完整结果。

## 独立审查

已完成一次独立只读审查，未让审查者修改代码、运行浏览器或接触真实数据。首轮发现凭据镜像、Cookie轮换、多操作GraphQL、空闲日志失败、启动IPC断开、Bearer变化及Windows ACL问题。

上述问题分别补了过滤/撤销/ACK与取消清理逻辑及合成测试；Windows没有用文档豁免：在真正落实ACL及实机验证前直接拒绝运行。第二轮静态复查确认6项原P1修复，另发现超过4096字符的Bearer未进入身份指纹。已将完整认证指纹与展示脱敏分离，补长Bearer、重复认证参数及巨大数差异测试；5个Node场景组、42项Python检查重新通过。最终独立静态复查确认最后P1可关闭，本次小修复无确证阻塞。此结论只覆盖已审查问题，不是审查者亲自执行测试或所有平台通过。

## 明确尚未完成

- Codex、Claude Code、Pi、OpenCode各自模型从需求到交付的完整行为；宿主后台子进程、权限、取消策略差异。
- Windows ACL实现/双用户验证、Windows桌面/文件锁/硬链接、Linux实机、其他Mac。
- HTTPS真实后台、SSO、MFA、登录过期后的人工恢复和复杂签名机制。
- 未发出可观察请求的前端账户切换：不能靠Cookie相等证明任意前端认证仍新鲜。未知机制必须停下按站点调查。
- 多标签并行观察、iframe内容、Service Worker、WebSocket和非JSON POST。新版已支持显式切换单个主页面及已存在的嵌套分页字段，不代表任意GraphQL变量/操作已验证。
- 完整三页终点/业务日期语义、金额语义、全部数据的去重/完整性；当前用例验证一页和下一页，并未实现通用全量采集器。
- 大响应的下载/解压硬内存上限。Playwright会缓冲响应，本版限制的是解析/留存，不能冒充流式内存沙箱。
- 任意未知编码/伪装秘密的通用DLP。默认只给结构，业务字段含义与外发权限不明时不得投影。
- SIGKILL操作系统强制终止、磁盘满和并发目录替换等完整故障矩阵；不把恢复元数据等同于可任意强杀浏览器。

只有合成运行及静态检查通过，不能宣称上述未测项完成。部署定时、发布、升级个人已安装Skill均需另行操作与授权。
